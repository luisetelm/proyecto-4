## Principios de diseño

Reglas que guían cada decisión visual del proyecto.

1. **Claridad ante todo** — Si el usuario tiene que pensar para entender algo, hay que simplificarlo.
2. **Consistencia** — Los mismos elementos siempre se ven y se comportan igual.
3. **Accesibilidad** — Contraste mínimo WCAG AA en todo el texto. Nunca color como único indicador.
4. **Espacio como elemento** — El espacio en blanco no es vacío, es parte del diseño.

## Voz y tono visual

Describe qué estilo visual se usa y cuál se evita.

**Se usa:**
- Fotografía natural, con luz real, sin filtros excesivos
- Iconografía de trazo fino (line icons)
- Composición asimétrica con puntos focales claros

**Se evita:**
- Degradados llamativos o neones
- Múltiples fuentes decorativas mezcladas
- Animaciones que distraigan del contenido
